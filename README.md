# CodeFactory DevOps

Projeto acadêmico desenvolvido para demonstrar a aplicação de práticas da Cultura DevOps na empresa fictícia CodeFactory Solutions.

## Descrição

A CodeFactory Solutions é uma pequena software house que enfrenta problemas relacionados à organização do desenvolvimento, versionamento de código, integração entre desenvolvedores, documentação e automação de processos.

Este projeto demonstra, de forma prática, como a adoção de práticas DevOps pode melhorar o processo de desenvolvimento e entrega de software.

## Objetivo

Demonstrar a utilização de práticas e ferramentas DevOps para tornar o desenvolvimento:

- Mais organizado;
- Colaborativo;
- Automatizado;
- Padronizado;
- Confiável.

Entre as práticas utilizadas estão:

- Controle de versão com Git;
- Repositório remoto no GitHub;
- Branches;
- Merge e Pull Requests;
- Testes automatizados;
- Docker;
- Integração Contínua.

## Tecnologias utilizadas

- Node.js
- Express
- JavaScript
- Jest
- Git
- GitHub
- Docker
- GitHub Actions
